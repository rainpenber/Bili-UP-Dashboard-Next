# 产品需求概要

## 背景

三人自媒体工作室需要统一处理：

- **商单制作**：从 Brief intake 到发布与结案的可视化流程。
- **流程督导**：阶段规则、责任人、截止时间（本仓库提供确定性状态机与 API）。
- **B 站 / 账号监控**：数据采集与展示（采集器在本仓库；语义理解在 Hermes）。

## WP-000 范围（Bootstrap）

本阶段仅交付可运行的 monorepo 基线，**不**实现业务功能。

| 在范围内                                   | 不在范围内                          |
| ------------------------------------------ | ----------------------------------- |
| Health API、共享契约、一个示例工作流纯函数 | 数据库迁移、ORM、真实 B 站/微信集成 |
| 可识别项目的 Web 壳 + API 健康展示         | Hermes、PDF/网页解析、生产部署      |
| Docker Compose 开发用 PostgreSQL           | 生产密钥与真实数据                  |

## 用户与角色（后续 WP）

- 制作人、商务、运营督导（三人工作室）。

## 非功能

- TypeScript 严格模式、CI 门禁、依赖克制。
- 所有外部智能能力通过 Hermes 边界接入，不在此仓库复制。
