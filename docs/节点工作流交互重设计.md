# 节点工作流交互重设计

原型 `/workflow-mock` 先把交互定下来。I-1 起，项目详情和集成设置里的流程画布改用同一套节点卡片；数据库和流程引擎的写入仍按后面的集成步骤接。

原型路由：`/workflow-mock`。数据在页面内存里，刷新即恢复。

## 设计基准

产品方对现有工作流编辑器的原话，逐字保留：

> 操作太繁琐，UI 文案非常不清晰，导致我根本不知道该怎么操作，上面的说明也很繁琐

> 节点图没做完，现在的这个新的我无法验证好不好用

> 用小拉选框来进行节点和节点之间连接，这个非常蠢

期望的使用方式：

> 非常简洁的一个框；下拉选单选择已有的工作流（V1、V2、V3 这种）；先不展示流程图，点开以后是一个类似达芬奇（DaVinci Resolve Fusion）的工作节点流，可以自由拖拽所有节点、自由添加和删除节点

> 干脆让 Cursor 直接重新设计这个可拖拽的、加上快捷键编辑的节点工作流

「类似达芬奇」指 DaVinci Resolve 的 Fusion 节点编辑体验：节点自由摆放、从端口拖出连线、卡片干净。本设计采用这套操作，画布用现有的 `@xyflow/react` 实现，初次排布用 dagre。

文案原则：一眼就懂，没有一句多余。说明放在本文，不放在界面上。

## 信息架构

两处界面，顺序固定：

1. **入口框**。只选版本，不画流程。
2. **节点画布**。点「打开」之后才出现。在这里拖节点、从端口连线、添加、删除。

同一套界面放在两个位置，布局相同，差在作用对象：

| 位置                                                 | 框上的字 | 打开之后改的是 |
| ---------------------------------------------------- | -------- | -------------- |
| 项目详情（替换现在的「完整工作流图」）               | 流程     | 这个项目       |
| 集成与设置（替换现在的「新项目默认流程」整块编辑器） | 默认流程 | 之后新建的项目 |

版本下拉都是已有工作流：V1、V2、V3。项目详情打开的是该项目正在用的那一版；设置页打开的是模板的那一版。原型用同一条路由把这条路径走完，下拉里放三版 mock，不区分项目和模板的真实数据。

从信息上拿掉这些东西：

- 入口上的流程图、图例、结构编辑面板、「从 / 到」下拉连线、连接清单、长段演示说明。
- 画布上的状态徽标、侧栏说明书、删除确认长文。

状态（开始、完成、卡住、退回）留在选中节点后的一行里，本阶段原型先不放这些按钮，避免把已经否决的操作堆回画布。对应新文案见文末清单，下一阶段再接到真实页面。

## 界面一：入口框

布局就一块卡片，竖排三行：

```
┌─────────────────────┐
│ 流程                │
│ [ V2            ▾ ] │
│ [ 打开 ]            │
└─────────────────────┘
```

设置页把标题换成「默认流程」，下面可以有一句：「只影响新项目」。项目页不写这句。原型标题用「流程」，不写补充句。

交互：

1. 进入页面，只有这个框。没有节点，没有连线。
2. 下拉改 V1 / V2 / V3。图仍然不出现。
3. 点「打开」，进入该版本的画布。
4. 画布里点「返回」，回到这个框，下拉停在刚才的版本。再次打开，看到刚才在本页内存里的改动。

## 界面二：节点画布

点开后占满内容区。上沿一条工具条，下面整面是画布。

```
┌──────────────────────────────────────────┐
│ 返回    V2                    整理  复位 │
│                                          │
│     (询单)──(大纲)──(文案)──·──(A-roll)  │
│                        (预拍摄)↗         │
│                                          │
└──────────────────────────────────────────┘
```

`·` 是汇合圆点：看得见、拖得动，不是一张卡片。

工具条从左到右：

- 「返回」
- 当前版本，纯文字：V1 / V2 / V3
- 「整理」：按当前的点和线重新排一次，可撤销
- 「复位」：回到能看全图的画面，不改数据
- 工具条下方一行快捷键提示

没有「添加」输入框。按 A，或在空白处右键「增加节点」，节点直接出现在画面中央或光标处，标题处就是文本框，并自动聚焦。

画布：

- 深色底、淡点阵。节点是深色圆角卡片，只写名字。短标题把卡片收窄（有最小宽度），最长约 200px，更长就换行。
- 每个步骤节点左侧一个圆点（进）、右侧一个圆点（出）。圆点、标题和同一行上的汇合点中心在同一条水平线上。标题换行或进入改名时，圆点仍贴着卡片中心。
- 连线是端口之间的曲线。
- 第一次打开时，dagre 从左到右排一次，画面停在流程起点，比例为 1。按 F 再看全图。之后位置以拖拽为准，不再自动重排。
- 拖空白平移，滚轮缩放。
- 节点出现、连线出现、右键菜单、进入和离开改名，都用大约 120ms 的淡入，不夸张。

交互：

1. 拖卡片移动该节点。松手记入撤销。单击只选中，不进入改名。
2. 从右侧圆点拖到另一个节点的左侧圆点，松手连上。
3. 拖到自己、重复连、或会成环：线弹回，顶上闪一句原因。
4. 点选节点或连线，按 Delete / Backspace，或右键「删除」，立刻去掉。连到它的线一起去掉。用「撤销」回来。
5. 按 A 或右键「增加节点」后直接改名。选中已有节点后按 Enter 也进入改名，再按 Enter 确认，点到别处也会确认。Enter 只改标题，不把节点展开。名字空着就存成「流程节点」。Esc 取消：已有节点恢复原名；新建且还是空的，把这个节点丢掉。右键「修改节点名称」同样进入改名。重名仍在顶上闪一句。
6. 悬停时节点右上角有一个按钮。点它，卡片就地变高，标题下面是一排「未完成 / 进行中 / 阻塞 / 完成」。点哪格切到哪格，边框颜色跟着变。只有「阻塞」下面才多一行原因。再点按钮收回去，被推开的邻居回到原位。展开时这个按钮一直留在右上角。这些只改 mock 显示，不接真实流程，也不重排整张图。
7. 「撤销」「重做」覆盖：移动、连线、删线、添加、删除、改名。右键菜单里也能撤销和重做。

连线只从端口拖到端口。

## 汇合节点

汇合节点不是卡片。它是一颗约 10px 的圆点，线在圆点上汇入、分出。

- 不写名字，不画状态，没有操作。
- 拖圆点本体是移动。松手记入撤销，撤销后回到原位。
- 鼠标移到圆点上，左右才出现更小的 in / out 端口。只能从这两个端口接线：步骤右端口拖到 in，out 拖到步骤左端口。两个汇合圆点不能直接相连。
- 空白处右键可以增加汇合点。圆点右键可以删除汇合点，连在它上面的线一起去掉。右键一条线可以删除这条线。这些都能撤销。
- 不可选、不可聚焦。快捷键全选、Delete 都跳过它。

原型里有两处这样的锚点，对应现在图上的两处会合：文案 / 预拍摄进入制作之前，发布之后分到结算、分发、数据维护、其他。数据模型里的「汇合节点」也走同一条渲染规则。

## 快捷键

选中一个步骤节点后按 Enter 进入改名。名称框里再按 Enter 确认，Esc 取消这次改名。焦点在输入框里时，只有撤销、重做和 Esc 生效，Enter 不会另开一个编辑。其余键等输入结束再用。

| 操作                         | 键                                   |
| ---------------------------- | ------------------------------------ |
| 删除选中的节点或连线         | Delete，或 Backspace                 |
| 撤销                         | Ctrl+Z，或 ⌘+Z                       |
| 重做                         | Ctrl+Shift+Z，⌘+Shift+Z，Ctrl+Y，⌘+Y |
| 添加节点                     | A                                    |
| 进入改名                     | 选中节点后 Enter                     |
| 确认名称                     | 再按 Enter，或点到名称框外面         |
| 取消改名，或取消选中         | Esc                                  |
| 全选步骤节点（不含汇合锚点） | Ctrl+A，或 ⌘+A                       |
| 适配画面                     | F                                    |
| 整理                         | L                                    |
| 在画面中央增加汇合点         | J                                    |
| 移动节点                     | 拖卡片                               |
| 连线                         | 从右侧圆点拖到左侧圆点               |
| 断开                         | 点中连线，再 Delete                  |
| 平移                         | 拖空白                               |
| 缩放                         | 滚轮                                 |

界面上只留一行按键提示。

## 方向切换

工具条上有「横向 / 纵向」。当前按下的那个就是整张画布的方向，不是每个节点各自横竖。

- 横向：进端口在左，出端口在右，汇合圆点也是左右，从上一次整理的从左到右排布。
- 纵向：进端口在上，出端口在下，汇合圆点也是上下，从上到下排布。卡片里的字不改成竖排。

切过去会按新方向重新排一次，点和线都还在。之后按「整理」也用当前方向。撤销可以回到切换前的位置和方向。展开时如果挡住邻居，纵向优先往上下推开。

## 原型

- 路径：`/workflow-mock`
- 侧栏不放入口，避免改到现有页面的导航。
- 本地：仓库根目录 `bun install` 之后，`cd apps/web && bun run dev`，浏览器打开 `/workflow-mock`。
- 下拉有 V1、V2、V3 三版 mock。V2 比 V1 多「样片」。V3 用「外拍」替换「AI 后期」，并去掉「其他」。
- 能走完：选版本 → 打开 → 拖节点 → 从端口拖线 → 按 A 改名 → 删除 → 撤销。汇合圆点可拖、可从左右端口接线。

## I-1 真实画布（只读展示 + 内联改名）

项目详情里的流程，和集成设置里的数据库默认模板，都改用原型那套卡片、金色汇合圆点、方向切换、整理 / 复位、MiniMap 和 Enter 改名。旧的「从 / 到」下拉和侧栏说明不再渲染。

真实状态进四格：

| 数据库 / 演示状态   | 四格   | 颜色                                                                |
| ------------------- | ------ | ------------------------------------------------------------------- |
| `completed`、`done` | 完成   | 绿                                                                  |
| `in_progress`       | 进行中 | 蓝                                                                  |
| `blocked`           | 阻塞   | 橙红。原因只读，有记录才显示                                        |
| `not_reached`       | 未完成 | 灰                                                                  |
| `not_applicable`    | 未完成 | 灰。没有第五格；卡片用 `data-workflow-status="not_applicable"` 区分 |

四格这一轮只展示，不写回。演示图的改名走已有 `renameWorkflowNode`，Ctrl+Z 能撤销。数据库里的项目和已发布模板也能改名，但只留在本页：当前接口没有改名路由。增删节点、连线、推进和完成留到 I-2 / I-3。

UUID 项目打开 `/projects/:projectId` 时读取 `GET /api/v1/commercial/projects/:id/workflow`。演示 id（如 `proj-snack-crisp`）仍用页内流程，画布相同。集成设置顶部展示 `GET /api/v1/commercial/templates/default`。
