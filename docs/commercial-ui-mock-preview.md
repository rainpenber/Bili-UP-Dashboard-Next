# 商单 UI Mock 预览说明

本里程碑（WP-004R2-1A）仅供产品负责人点按验收，数据来自前端内置 Mock，刷新页面不会同步微信或后台。

建议验收顺序：

1. **今日看板** `/` — 三块待办与阻塞汇总，点任一行进入项目详情。
2. **项目** `/projects` — 卡片仅名称与阶段；展开可看卡点和开放事项。
3. **项目详情** `/projects/proj-nev-spring` — 含大纲来回仍是一条待办的样例；未发布项目可试「进入发布状态」。
4. **集成与设置** `/integrations` — 底部「新项目默认流程」只读图。

错误态：任意商单页 URL 追加 `?commercialMockError=1` 查看加载失败与重试。
