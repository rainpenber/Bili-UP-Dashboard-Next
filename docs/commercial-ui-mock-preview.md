# 商单 UI Mock 预览说明

本里程碑（WP-004R2-1C）仅供产品负责人点按验收，数据来自前端内置 Mock，刷新页面不会同步微信或后台。

建议验收顺序：

1. **今日看板** `/` — 三块待办与阻塞汇总，点任一行进入项目详情。
2. **项目** `/projects` — 卡片仅名称与阶段；展开可看卡点和开放事项。
3. **项目详情** `/projects/proj-snack-crisp` — 推进/回退/阻塞（原因可选）、结构增删与连接；撤销/重做应恢复节点与连线。
4. **集成与设置** `/integrations` — 编辑新项目默认流程草稿、发布版本并回看旧版本（明示不影响已有项目）。

错误态：任意商单页 URL 追加 `?commercialMockError=1` 查看加载失败与重试。
