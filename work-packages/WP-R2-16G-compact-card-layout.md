# WP-R2-16G 卡片紧凑排版

## 行为

监控中心视频 / UP 主 / 动态卡片正面操作区与信息块同一横向区域垂直居中，不再独占底行抬高卡片。

- **分栏/列表**：封面或头像、紧凑信息块、详情+主操作两键横向排列；标题按可用宽度单行 `truncate` + `title` 悬停全名。视频缩略图真正 16:9（约 96×54，`aspect-video w-24`）；UP 头像保持圆形。状态徽标与失败红点、播放/在线或粉丝摘要保留。视频图钉仍在封面角，不进入操作条。
- **视频网格**：保留四列与整宽 16:9 大封面；封面下信息区左侧标题/指标/分类时间，右侧两键上移并与信息块居中；移除仅为按钮保留的底部空白行。
- **UP 网格 / 动态**：同类排版同步。动态无封面，不伪造图片。卡片操作仍仅详情 + 开始/暂停/恢复。
- **极窄宽度**：外层允许 `flex-wrap` 回退，避免宽屏方案在手机硬挤导致溢出或横向滚动。

## 非目标

不改采集、调度、API、数据库、置顶与排序语义；不改详情页次要入口；不引入新组件库。
