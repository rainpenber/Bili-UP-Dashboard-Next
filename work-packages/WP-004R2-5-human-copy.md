# WP-004R2-5 — 全站文案人性化

把用户看得见的界面文字从设计文档说法改成日常说法。数据模型、接口、数据库和工作流编辑器都没有动。

## 原则

- 图表图例、坐标轴、详情标签用「播放量、点赞、投币、收藏、分享、弹幕、评论、转发、粉丝数、在线观看」。
- 「指标 / 指标序列 / 实体 / 采样 / 元数据」改成「数据 / 变化 / 记录 / 基本信息」。
- 空态、错误和说明尽量一句说完。
- 在线观看的 `1000+` 显示成「1千+」，不再写「下界」。

## 不改

- 工作流编辑器、节点操作面板、默认流程编辑器里的句子。
- `/workflow-mock` 路由（本包不新建、不修改）。
