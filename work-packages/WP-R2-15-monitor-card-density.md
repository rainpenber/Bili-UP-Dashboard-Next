# WP-R2-15 监控卡片与详情页信息精简

## 行为

视频 / UP 主卡片改成左右两栏：左侧封面、标题、身份和一行最新指标；右侧垂直居中放操作。主操作是开始、暂停或恢复，旁边只保留「查看详情」和「更多」。监控设置、查看日志、进入商单、立即采集和移除收在「更多」里。

常驻状态只有未监控、监控中、已暂停。不展示频率、下一次计划、等待、执行中或「暂无进行中的任务」。点击状态徽标或「监控详情」后，在同一张卡片里展开频率和上一次成功采集时间。自动模式只写「自动」；固定模式写「固定间隔 · 每 N 分钟」。最近一次失败且有错误文本时，卡片上多一行「最近失败：…」。没有错误文本时不显示占位。

详情页把同一组状态放到标题和元数据之间：状态徽标、开始 / 暂停 / 恢复、监控详情、查看日志。无样本目标仍能看到这条监控条，以及「尚无采集数据」。图表、作者信息和视频列表位置不变。

暂停、恢复、设置和采集语义不变。
