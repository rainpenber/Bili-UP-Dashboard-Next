# WP-R2-16H 监控筛选行与视频操作按钮排布

## 行为

1. **筛选区响应式栅格**：视频 / UP 主 tab 筛选栏使用 `grid`，`1` 列（窄）→ `sm:2` 列 → `xl:4` 列；每列 `min-w-0`，标签 `whitespace-nowrap`。关键词输入 `min-w-[12rem] flex-1`，避免窄宽度下标签竖排或输入框被挤成窄条。
2. **分类文案**：标签「分类（视频标签）」，placeholder「如：游戏、数码」，`title`「按视频分类过滤，留空表示全部」；仍写 URL `category`，查询语义不变。
3. **只看我的**：删除 Toggle 下方「昵称 · mid」行；身份说明放入按钮 `title` / `aria-description`。
4. **详情操作单一行**：详情页 / 分栏右侧 `layout=detail` 的监控状态徽标、暂停/恢复、监控详情、查看日志、查看详情、监控设置、立即采集、移除（及商单跳转）放在同一个 `role=group` flex-wrap 容器；窄屏自然换行，不与状态徽标拆成两行容器。

## 非目标

不改图表 / 发现逻辑；不碰商业 / 19C / 19E；不加迁移；不改真实采集开关；不改 onlyMine 查询语义与卡片两键布局。
