# WP-R2-11 全量 HTTP API 联调与契约收口

起点：`cursor/legacy-csv-sync-541e` @ `3989b9635198d45e90e0c37dd65ad156eb5e2733`。本包只验收当前已注册的 HTTP API，不合并其他 PR，不新增领域实体，不改调度算法、状态机、迁移、前端视觉、限流或日志队列。

## 不变量

1. **覆盖完整可核对**：生产入口实际注册的 method + 完整路径 = `docs/architecture/api-inventory.json` = 本包执行集合。SPA / 静态资源 handler 排除。重复挂载不重复计数。数字以程序化统计为准。
2. **HTTP 合同与存储一致**：请求走公开路由和请求/响应合同；写入后用读接口和 SQL 读回。非法输入、缺失资源和冲突返回约定的 4xx，且没有非预期写入。BigInt 用字符串。历史评论 NULL、在线 NULL 与 0 分开。作者默认 240 分钟，视频自动档为 15 / 120 / 360，固定频率为 5–10080。读响应保留 `intervalMode`。
3. **隔离、离线、可复跑**：真 PostgreSQL、全迁移、每个运行独立库。不连接历史库或共享库，不访问 B 站或 CDN，不接收真实凭据。刷新和采集只走注入的 transport / provider，并核对持久化结果。失败时失败关闭，不能提前 return 或静默跳过。

## 已知合同差

创建请求仍把频率限制在旧枚举，240 被拒绝；`interval_mode` 存在于数据库，读响应没有带出。兼容修复只放宽请求校验到 5–10080，并在读写路径映射已有的 `auto` / `fixed`。不把作者默认改成 360，不改采集排期算法，不改迁移。

## 允许与禁止

允许：`apps/api/src/**` 的入口组装、路由映射、测试与覆盖工具；`packages/contracts` 的兼容校验；`packages/db` 里 API 用到的窄读写映射和保留验收库的测试辅助；清单、覆盖报告、本规格、CI 的 fail-closed 步骤。

禁止：`apps/web/src/**`、`packages/db/migrations/**`、`packages/observability/**` 的缓冲与退出 flush、采集器调度与鉴权、Docker / Compose、宿主脚本、部署、DROP 共享库或生产库。验收库只关闭连接，不执行 DROP DATABASE。

## 验收

- 每条注册路由至少一个成功调用和合同断言；写接口有持久化读回；适用时覆盖非法输入、缺失、重复、过期 token、冲突和拒绝零写。
- CSV 导入核对批次、冲突、拒绝行和读回。元数据刷新用注入 provider 核对成功、失败、部分失败、队列和幂等。图片只用隔离临时目录。
- 监控项覆盖创建、编辑、暂停、恢复、立即运行、软删、重复、非法标识，以及 240、120、auto / fixed。离线 worker 核对 job 和样本。
- 商单沿既有写路径做推进、完成、回退、阻塞、确认、计划日期、发布、事项关闭和取消，并核对跨项目、过期 token、前置未满足的拒绝。
- ops 只用本库生成的记录，核对过滤、分页、关联和脱敏。
- CI 设置 `REQUIRE_POSTGRES=1`，真 PostgreSQL 上跑全量接口测试。异步任务等到结束并断言结果。
- 覆盖报告为 JSON + Markdown，由实际请求记录生成。
