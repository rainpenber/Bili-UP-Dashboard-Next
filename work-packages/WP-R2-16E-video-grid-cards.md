# WP-R2-16E 视频网格卡片精简 + 大封面

## 行为

视频 tab 的**网格**视图卡片改为整宽 16:9 封面：状态徽标与标题单行截断同行，播放量（万/千 + 精确值）与在线人数、分类与更新时间各占一行，底部仅「详情」与主操作（开始监控 / 暂停 / 恢复）。采集失败时在状态徽标上显示红色小圆点，不另起失败文案行。

卡片正面不再出现监控详情展开、更多、查看日志、监控设置、立即采集、移除、关联商单；频率、计划开始、上次成功采集只在详情页或设置对话框中展示。分栏（列表）视图与 UP 主 / 动态卡片保持原交互。

网格列数：≥1280px 四列，1024–1279 三列，640–1023 两列，更窄一列。详情页直接提供监控设置、立即采集、查看日志、移除、关联商单入口（不新造页面）。

## 非目标

不改采集、调度、API 语义；不改列表分栏布局与动态 tab。
