# WP-R2-13 视频与 UP 主监控卡片

## 行为

监控中心的主页面是视频、UP 主、动态。`?tab=targets` 进入视频页，不再单独做一套监控项管理。

视频和 UP 主可以新增监控。弹窗预选类型，接受完整 BV / UID，以及 `www.bilibili.com/video/BV…`、`m.bilibili.com/video/BV…`、`space.bilibili.com/UID` 长链接。短链直接拒绝，不发外网请求。默认频率是自动：视频按发布年龄 15/120/360 分钟，UP 主 240 分钟。固定频率才提交已有间隔。重复新增返回既有目标，不恢复暂停、不覆盖设置。

列表来自 `GET /api/v1/monitor/cards`。实体和活动目标全外连接，所以没有 `videos` / `creators` 行、也没有样本的目标仍出现，并显示「尚无采集数据」。状态是未监控、监控中、已暂停；执行情况是等待、执行中、最近失败或暂无进行中的任务。`enabled` 不显示成「正在采集」。筛选、搜索、分页和总数在服务端一次完成。

启停、设置、立即采集和移除走既有 targets 接口。暂停后不再领取新的自动任务；暂停前已经领取的任务可以写完。恢复只从当前时刻接上一条，不补跑暂停期间的全部轮次。

视频商单来自 `project_publish_records.bvid` 与 `project_monitor_contracts.bvid` 的并集，再读项目 id 和名称。不用 `linked_bvid`，也不按标题猜测。没有关联就不显示跳转。UP 主没有对应的项目外键，卡片不显示商单入口。

「查看日志」打开 `/ops?targetId=…`。底部仍保留「最近采集任务」。

## 非目标

不新增迁移，不改调度器，不采集动态，不发现 UP 主新内容，不给粉丝曲线加内容标点。
