# WP-R2-27B — 粉丝图事件点与数据窗口重做

基线：`wp-r2-int03`（含 27A/27C）。只改前端图表与相关测试，不改 API/DB。

## 范围

1. **数据窗口**：`GET .../metrics?all=1` 取全量；默认 dataZoom 以最后样本向前 90 天；slider 覆盖全部历史；纵轴按可见窗口计算；大样本关闭动画并启用 `large`/`lttb`。
2. **事件点**：空心圆（透明填充 + 对比色描边，主题 `chart-3` 琥珀）；hover 放大到 14。
3. **Tooltip**：约 300px 宽、标题最多 3 行省略；视频迷你封面 / 动态图标占位；整条可点（视频 / 动态详情）；无样本不借用最近粉丝数。
4. **「显示全部事件」**：默认只画落在粉丝样本时间范围内的事件；打开后横轴扩展到最早事件，URL `?allEvents=1`；无样本区间浅色底。
5. **文案 / 控件**：去掉说明段与「另有 N 条」提示、去掉 toolbox；图例仅「粉丝数」「事件」。
6. **动态补齐**：打开 UP 详情时静默 `POST .../dynamics/sync`（缺路由降级），成功后 invalidate 事件查询。
