# WP-R2-15B 监控列表分栏 / 网格

## 行为

视频和 UP 主筛选栏右侧增加布局切换，使用 Radix Toggle Group 单选「分栏 / 网格」。缺省和无法识别的 `view` 都是分栏：左侧对象卡片，右侧所选对象的趋势图。网格把卡片按可用宽度排成多列，分页紧跟卡片，所选对象的趋势图放在整块卡片区域下方。

`view=split|grid` 写在监控页 URL 里。切布局不改关键词、分类、监控状态、页码和已选对象，也不改卡片接口的 `pageSize`。详情链接带着当前查询返回，刷新和浏览器返回都留在原来的布局。再点当前已选项不会清空选择。动态页仍是原来的左右列表，不提供这个切换。

网格卡片默认把操作收在右侧窄列，卡片本身宽到大约 40rem 时才把按钮排成一行，避免标题被挤成几个字。列数用 `auto-fit` 和大约 26rem 的最小列宽，不固定四列。窄屏两种布局都变成单列。
