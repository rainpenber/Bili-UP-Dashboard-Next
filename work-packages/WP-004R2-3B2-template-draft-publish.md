# WP-004R2-3B2 — 默认流程模板草稿、发布，以及从版本创建项目

## 目标

默认流程可以在真实 API 上从当前已发布版本开草稿、改结构、发布成新版本或丢弃。发布把新版本设为默认，不改已有项目。可以从某个已发布版本创建项目，实例图按该版本物化，用来观察发布确实生效。

## 范围

- 契约：`packages/contracts` 的模板工作区和创建项目请求/响应。
- 写 API：草稿的增删改节点和连接、发布、丢弃；`POST /projects`。
- 迁移 `005`：已发布版本仍不能改内容，只允许移动 `is_default`；同一版本内节点名称去空格后唯一。
- 集成与设置页改为调用上述接口。删除确认沿用已评审的连接名单；成环和重名展示服务端原文。
- 创建成功后打开 `/projects/:projectId/graph`，用真实流程接口画出物化后的图。

## 同名项目

`commercial_projects.name` 只有 `TEXT NOT NULL`。表上没有名称的唯一约束，也没有只覆盖 `name` 的唯一索引。因此同名项目允许创建，本包不另加规则。

## 版本号

发布后的版本号保持创建草稿时分配的整数，并且因为已发布行不能删除，所以不会被复用。丢弃尚未发布的草稿会删掉那一行，下一次草稿取当前最大版本加 1，可能再次使用刚丢弃的号。
