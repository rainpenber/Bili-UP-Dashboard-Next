# WP-R2-27C — 监控卡片动作精简 + 移除二次确认 + 在线人数取上界

基线：PR #69 head。只改前端卡片与视频/UP 详情页；不改图表实现（27B）与 API（27A）。

## 行为

### 视频卡片动作条

列表 / 网格 / 分栏右侧面板仅保留：

1. 状态徽标（监控中 / 已暂停 / 未监控 + 失败红点）— 纯展示
2. 主操作：未监控→开始监控，监控中→暂停，已暂停→继续
3. 查看详情 → `/monitoring/videos/:bvid`
4. 查看项目 → 仅当 `projects.length > 0`

次要操作（监控详情、查看日志、监控设置、立即采集、移除、关联商单）只出现在视频详情页工具条。

UP 主 / 动态卡片保持既有动作集（主操作 + 置顶 + B 站外链），不回填被删按钮。

### 移除 = 高危

- 详情页「移除」为 destructive 样式
- `AlertDialog` 二次确认；遮罩 / Esc / 取消不调用删除；确认后调用一次删除接口，成功 toast + 回列表，失败保留弹窗并展示错误

### 峰值在线

- 卡片摘要：`peakOnlineFromSamples` 取最近窗口最大值，文案「峰值在线」；无样本「无在线数据」（不显示 0）
- 详情图表仍为逐点曲线；详情元数据标注「在线观看（逐点）」

## 验收

- `bun run format:check` / `typecheck` / `build` / web 测试全绿
- 1440 / 390 宽度下视频卡片动作 `flex-nowrap` 不换行溢出
- 不改后端契约
