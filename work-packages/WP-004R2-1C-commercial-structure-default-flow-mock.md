# WP-004R2-1C — 工作流结构编辑 + 默认流程版本（Mock）

## 目标

在 R2-1B 已验收的项目流程图编辑壳上，增加**结构编辑**（增删节点、连接/断开）与**集成与设置**页的默认流程草稿/发布版本；阻塞原因改为可选。仍为前端 Mock，无数据库/真实 API。

## 范围

- 项目详情：结构编辑进入同一 undo/redo；删节点前确认将移除的连接；重名与成环连接给出可读拒绝。
- `/integrations`：默认同编辑语义；保存草稿、发布版本、回看旧版本；明示演示数据且发布不影响已有项目。
- 阻塞原因可选；空原因不渲染空行。

## 未做

- 画布卡片高度与连线重叠等已知渲染瑕疵（产品明确延后）。
