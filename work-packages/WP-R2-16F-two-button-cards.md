# WP-R2-16F 分栏与网格统一为两个按钮

## 行为

监控中心视频、UP 主、动态三个 tab 的卡片正面统一为「详情 + 主操作（开始监控 / 暂停 / 恢复）」两键。状态徽标在标题行左侧（监控中绿 / 已暂停琥珀 / 未监控灰）；采集失败时徽标加红点与 `aria-label`，不另起失败文案行。标题单行 `truncate` + `title` 全名。

- **视频**：分栏左侧改为两键；网格保持 16E（大封面 16:9，不回退）。分栏「详情」选中卡片打开右侧面板；网格「详情」跳详情页。
- **UP 主**：分栏与网格均为两键；网格用大圆形头像 + 名称 + 粉丝，与视频网格同一卡片骨架与高度节奏。
- **动态**：分栏与网格均为两键；布局开关对动态生效。无封面，网格以动态 id + 赞/评/转摘要 + 状态徽标组成；「详情」始终跳 `/monitoring/dynamics/:id`。无采样显示「尚无采集数据」。

卡片正面删除：更多、监控详情展开、查看日志、失败整行文字、频率 / 计划开始 / 上次成功。这些能力留在详情页，以及视频/UP 分栏右侧详情面板。

## 非目标

不改采集、调度、API 语义与路由；不改视频网格（16E）视觉；不改详情页既有能力；不引入新依赖。
