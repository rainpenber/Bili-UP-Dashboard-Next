# WP-R2-22A — 真实商单来源档期只读展示

## 行为

- 列表 / 详情读接口增加 `sourceWindow: { startAt, endAt, reminderAt } | null`。
- 数据只从 `commercial_project_sources.payload` 抽取上述三个日期字段；不暴露 payload 其他字段与客户聊天原文。
- 无来源绑定 → `sourceWindow: null`；有绑定但无日期 → 对象字段全 `null`（前端「来源未给档期」）。
- 详情「排期」卡：无项目自有排期时展示来源档期（未确认）；有已确认节点排期时仍以项目排期为主，来源档期为次要行。
- 不写 `wf_nodes.planned_at`，不生成占位日期，不参与逾期 / 用时统计；不加迁移。

## 非目标

- 不改归档、发布、监控逻辑；不部署生产；不做字段语义推断。

## 验收

- 海信E8S（9/18–10/21）、大疆 Pocket4（9/1–10/19）能显示来源档期；未给档期显示「来源未给档期」。
- 归档样例不回归；文案区分「来源档期（未确认）」与「已确认排期」。
- `format:check` / `lint` / `build` / 相关测试全绿。
