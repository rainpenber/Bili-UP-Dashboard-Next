# WP-R2-16D 动态监控页面收尾（新增 / 启停 / 详情与日志）

## 边界

只做监控中心 **动态 tab** 的页面能力：新增、暂停/恢复、详情指标与最近采集记录。不改视频/UP 行为，不改采集频率与后端调度，不重做卡片视觉骨架。

## 交付

1. **新增**：动态 tab 提供「新增监控」；接受十进制动态 id 或 `https://t.bilibili.com/<id>`；非法输入就地报错且不发请求；默认固定 60 分钟，可改既有档位。
2. **启停**：列表与详情复用既有 `PATCH /targets/:id`；失败不乐观成功，错误可读；操作后列表/详情随 `['monitor']` 失效刷新。
3. **详情与日志**：选中动态展示点赞/评论/转发与最近采集时间；展开区读既有 ops `collector-jobs`；详情页挂启停条。
4. **最小读端点**：`GET /targets/of/:type/:externalId`；动态列表/详情 JOIN `monitor_targets` 返回 `target` 摘要。

## 不变量

- 写操作只走既有目标 API 与鉴权。
- 无监控的动态仍可浏览历史指标。
- 不引入新依赖或设计系统；不改 Compose/CI/凭据或真实上游。
